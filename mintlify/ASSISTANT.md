## Core Concepts & Terminology
- **AppKernel**: The entry point for HTTP requests, responsible for global middleware and dispatching.
- **Provider**: A service lifecycle hook used to register and boot container dependencies.
- **RouteParams**: The standard class used to retrieve strongly typed parameters from a route path.
