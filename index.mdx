Archery is a Laravel-inspired web framework built directly on `dart:io`. It provides the structure of a full framework—an application container, service providers, an HTTP kernel, middleware, routing, templates, authentication, sessions, and an ORM—while keeping the runtime explicit and readable.

## When Archery is a good fit

Use Archery when you want to build a server-rendered website, JSON API, internal application, or small service in Dart without assembling the application lifecycle from unrelated packages.

Archery is designed around four ideas:

- **Explicit over magical.** Application startup and request handling remain visible in your code.
- **Framework, not micro-router.** Routing is one part of a larger application structure.
- **Dart-native.** The server runs directly on `dart:io`.
- **Readable and adaptable.** Framework components can be inspected, extended, or replaced through providers and the container.

## Follow the learning path

<Steps>
  <Step title="Install Archery">
    Confirm your Dart version, create a project, add the package, and establish the default application directories.
  </Step>
  <Step title="Run the quickstart">
    Boot the application, register a route, and serve your first response through the HTTP kernel.
  </Step>
  <Step title="Learn the project structure">
    See which directories Archery uses by default and where application code belongs.
  </Step>
  <Step title="Understand the architecture">
    Follow startup and an incoming request through the container, providers, middleware, router, and handler.
  </Step>
  <Step title="Build a small application">
    Extend the server into a small JSON API with typed parameters and parsed request data.
  </Step>
</Steps>

<Warning>
  Archery 1.5.0 is a stable-alpha, early-production release. Its main APIs are usable, but internals and security hardening continue to evolve toward 2.0. Evaluate and load-test the framework for your workload before using it for mission-critical infrastructure.
</Warning>
